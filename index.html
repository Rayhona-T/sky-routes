How BFS Works

Breadth-First Search explores an unweighted map like a ripple in a pond: it finishes everything at distance 1 before touching anything at distance 2. That is exactly why it finds the shortest route first.

1

Nodes and airways

Every airport on the map is a node. Every airway that joins two neighbouring cells is an edge. Storms, mountains and closed airways simply remove edges — the map is a plain, unweighted graph.

2

A FIFO queue

BFS keeps a queue: first in, first out. The origin goes in first, so it comes out first. Neighbours are appended to the back, which forces the search to drain every node at the current distance before moving deeper.

+ C5D5B5C4 −
3

Level by level

Depth 0 is the departure airport, 1 is its four neighbours, 2 their neighbours, and so on. A node’s level is the smallest number of hops that can possibly reach it — BFS visits nodes in non-decreasing level order.

011223
4

The visited set

The moment a node is enqueued it is marked visited. Re-checking it later would waste time and could loop forever. Marking early also means each node is queued once, at its smallest possible level.

5

Parent pointers → path

When BFS discovers a node it remembers who discovered it. When the destination pops out of the queue, we walk those parent links backwards — destination to origin — and reverse the result. That chain is the shortest path.

6

Why shortest, guaranteed?

Every edge has the same cost, so the number of hops is the distance. Suppose BFS first reaches the destination via k hops. Before that moment it had already dequeued every node at levels 0…k−1 — so any other route must also have ≥ k hops. If a shorter route existed, BFS would have run out of closer nodes first. Nothing shorter can exist, so the first hit is optimal.

Depth-First Search (DFS) races down one branch and can return a long, winding route. BFS widens instead, which is why it wins here. On weighted graphs (where edges cost different amounts) you would reach for Dijkstra’s or A* instead.

The algorithm, in pseudocode

queue ← [start]                 // FIFO
visited ← { start }
parent[start] ← null
level[start] ← 0

while queue is not empty:
    node ← queue.pop_front()    // dequeue
    if node is destination: break
    for each neighbour of node:
        if neighbour not visited and airway open:
            parent[neighbour] ← node
            level[neighbour] ← level[node] + 1
            visited.add(neighbour)
            queue.push_back(neighbour)   // enqueue

path ← walk parent[] from destination back to start, then reverse
Level complete
