# ☁️ Sky Routes: The BFS Expedition

A polished, responsive browser-based puzzle game featuring a whimsical pastel aviation world. Players navigate custom maps by finding the shortest flight paths using the **Breadth-First Search (BFS)** algorithm[cite: 3].

---

## 🎮 Features
- **Pastel Aviation World:** Illustrated floating islands, oceans, mountains, clouds, and a charming plane character that reacts to discoveries and victories[cite: 3].
- **Algorithm Visualization:** Genuine BFS implementation using a FIFO queue, visited sets, level-by-level exploration, parent tracking, and shortest-path reconstruction[cite: 3].
- **Interactive Controls:** Step-by-step and autoplay modes with play, pause, reset, and speed controls[cite: 3].
- **Game Modes & Levels:** 
  - Three handcrafted levels with increasing difficulty (bridges, storms, and blocked airways)[cite: 3].
  - Free-play map editor where players can choose start/destination airports and place obstacles[cite: 3].
- **Educational Component:** A separate "How BFS Works" tutorial explaining why BFS guarantees the shortest path in unweighted graphs[cite: 3].
- **Responsive & Accessible:** Fully optimized for both desktop and mobile layouts with full keyboard accessibility[cite: 3].

---

## 🛠️ Tech Stack
- **HTML5** (Semantic layout and structure)[cite: 3]
- **CSS3** (Custom styling, atmospheric animations, and responsive design)[cite: 3]
- **Vanilla JavaScript (ES6+)** (Game logic, state management, and BFS algorithm implementation)[cite: 3]
- **SVG / Canvas** (Dynamic map rendering)[cite: 3]

*No external libraries, frameworks, or paid APIs were used—pure vanilla web technologies!*[cite: 3]
